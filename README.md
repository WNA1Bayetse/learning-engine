# Learning Engine

A simple command-line tool for tracking study sessions — logging subjects,
duration, and history to `study_log.json`.

## Files
- `tracker.py` — main script for logging and viewing study sessions
- `study_log.json` — persisted log of study sessions
- `.gitignore` — excludes environment/local files from version control

## Usage
```bash
python tracker.py
```

## Status
Personal project, actively maintained. Used as a test project for
experimenting with agentic engineering workflows (Antigravity + PCE
framework).
